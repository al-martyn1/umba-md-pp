# MD++ Alerts

MD++ Alerts - это аналог alerts в GitHub/GitLab Flaivored Markdown.

MD++ Alerts начинаются с тройного восклицания (!!!`), непосредственно за которым (без пробела) следует тип алерта. После типа алерта может
следовать заголовок алерта.

Если тип алерта не указан, будет использован тип **warning**.

Если Alerts не работают в целевом markdown (GitLab старых версий), то они будут оформлены как blockquote (через символ '>').

Алерт может быть одного из следующих типов:
- `note`, `n`;
- `tip`, `t`;
- `important`, `i`;
- `warning`, `w`;
- `caution`, `c`;
- `todo`, `d`.

Алерты аналогичны соответствующим в GFM/GLFM, кроме алерта `TODO`. Алерт `TODO` создаёт алерт средствами одного из существующих алертов, или через blockquote.
