# Тэги MD++

## Атрибуты

В тэгах MD++ есть ограниченная поддержка атрибутов HTML. Если значение атрибута не содержит пробелов, то его не обязательно заключать в кавычки.
Если значение содержит пробелы, его следует заключить в кавычки или апострофы. В строке, обрамлённой кавычками, могут встречаться апострофы,
и наборот. Нет способа использовать в значении одновременно кавычки и апострофы. HTML entities не поддерживаются.


## Вставка диаграмм и таблиц

Данные тэги позволяют вставлять диаграмму или таблицу из файла или непосредственно по месту.

###### **Тэги**


|Тэг|Описание|
|:---|:---|
|**csv-table**|вставляет таблицу из CSV формата.|
|**graph**|вставляет граф GraphViz (требуется установленный и прописанный в путях GraphViz).|
|**puml**|вставляет диаграмму PlantUML (требуется установленная и прописанная java и переменные среды с настройками PlantUML jar'а).|


Если требуется вставка из файла, то используется одиночный тэг:
```
<csv-table file="ИМЯ_ФАЙЛА.csv"/>
```

Можно проще, имя файла просто после тэга:
```
<csv-table/> ИМЯ_ФАЙЛА.csv
```

С заданием заголовка:
```
<csv-table/> ИМЯ_ФАЙЛА.csv Заголовок из нескольких слов
```

В последнем случае заголовком считается весь текст после имени файла до конца строки. Если имя файла содержит пробелы, его следует заключить в кавычки.


Можно приводить содержимое диаграммы или таблицы непосредственно в документе:
```
<csv-table>

Текст csv-файла

</csv-table>
```

### Тэг csv-table

Тэг 'csv-table' вставляет таблицу из CSV формата.

###### **Атрибуты**


|Атрибут|Описание|
|:---|:---|
|**title**|вставляет заголовок таблицы (надо уточнить, как).|
|**strict**|включает/выключает строгий разбор CSV (уточнить).|
|**sep**|задаёт разделитель, используемый в CSV-файле.|
|**quotation**, **quot**|Надо уточнить его действие.|
|**csv-title**|Надо уточнить его действие.|
|**multi-csv**|Позволяет из одного источника создать несколько таблиц.|
|**multi-title**|Надо уточнить его действие.|


#### Атрибут title

Атрибут 'title' вставляет заголовок таблицы (надо уточнить, как).

#### Атрибут strict

Атрибут 'strict' включает/выключает строгий разбор CSV (уточнить).
Значения 't'/'true'/'1'/'y' включают строгий режим.
Значения 'f'/'false'/'0'/'n' выключают строгий режим.

#### Атрибут sep

Атрибут 'sep' задаёт разделитель, используемый в CSV-файле.

Возможные значения:

|Значение|Описание|
|:---|:---|
|**auto**|Автоопределение разделителя полей.|
|**comma**|Разделитель - запятая.|
|**semicolon**|Разделитель - точка с запятой.|
|**colon**|Разделитель - двоеточие.|
|**hash**|Разделитель - свол решётка.|
|**vertical-bar**|Разделитель - вертикальная черта (символ OR).|
|**tab**|Разделитель - табуляция.|


#### Атрибут quotation/quot

Надо уточнить его действие.

Возможные значения:
###### **Опции**


**none** -
Нет квотирования.

**quot** -
Используется кавычка.

**apos** -
Используется апостроф.

**backtick** -
Используется символ backtick (обратный апостроф).


#### Атрибут csv-title

Надо уточнить его действие.

#### Атрибут multi-csv

Позволяет из одного источника создать несколько таблиц. Разделителем таблиц будет являтся строка, заданная данным тэгом.
Если значение не задано, или задана пустая строка, в качестве разделителя будет использоваться строка "<<<--->>>".

#### Атрибут multi-title

Надо уточнить его действие.

Если "multi-csv" разделитель не установлен, данный атрибут устанавливает его в значение по умолчанию "<<<--->>>".


### Тэг graph

Тэг 'graph' вставляет граф GraphViz (требуется установленный и прописанный в путях GraphViz).

###### **Атрибуты**


|Атрибут|Описание|
|:---|:---|
|**file**|имя входного файла, если требуется отображение графа из внешнего описания.|
|**save-as**|по умолчанию сгенерированное изображение сохраняется с сгенерированным именем файла. Данный атрибут позволяет явно задать имя файла изображения и устанавливает имя файла для сохранения (без расширения).|
|**scale**|масштаб (вроде в процентах)|
|**type**|тип графа (уточнить)|


### Тэг puml

Тэг 'puml' вставляет диаграмму PlantUML (требуется установленная и прописанная java и переменные среды с настройками PlantUML jar'а).

###### **Атрибуты**


|Атрибут|Описание|
|:---|:---|
|**file**|имя входного файла, если требуется отображение графа из внешнего описания.|
|**save-as**|по умолчанию сгенерированное изображение сохраняется с сгенерированным именем файла. Данный атрибут позволяет явно задать имя файла изображения и устанавливает имя файла для сохранения (без расширения).|
|**scale**|масштаб (вроде в процентах)|
|**type**|тип графа (уточнить)|


## Вставка списков значений

Списки значений служат для упрощенного оформления списков различных значений. Их действие
идентично, они отличаются только различными преднастройками. Преднастройки сделаны
таким образом, чтобы формировать представление списка значений, соответствующее их названию.
Преднастройки любого типа значений можно изменить из командной строки соответсвующими опциями.

Дополнительно, преднастройки можно переопределить в конкретном месте использования такого тэга.

Пример использования тэга вставки списка значений:

```
<def-list no-sec-title>
- CFGMETA_MK_ID_STRUCT
Преобразование имени структуры в числовой идентификатор структуры.
- CFGMETA_MK_ID_MEMBER
Преобразование имени поля структуры в числовой идентификатор поля структуры.
- CFGMETA_MK_ID_PAIR
Преобразование пары из имени структуры и имени поля структуры в пару числовых идентификаторов.
</def-list>
```

Приведённый выше список значений будет выглядеть следующим образом:

**CFGMETA_MK_ID_STRUCT** -
Преобразование имени структуры в числовой идентификатор структуры.

**CFGMETA_MK_ID_MEMBER** -
Преобразование имени поля структуры в числовой идентификатор поля структуры.

**CFGMETA_MK_ID_PAIR** -
Преобразование пары из имени структуры и имени поля структуры в пару числовых идентификаторов.


### Использование списков значений

Внутри тэга списка значений синтаксис предельно прост - маркер '-' (минус) начинает новый элемент, за ним в той же
строке следует "ключ" (термин) - наше значение, которое мы хотим описать. В последующих строках идёт описание значения, которое
заканчивается при обнаружении нового ключа, или по окончании списка значений (закрывающий тэг).

Значение ключа при обработке разбивается по запятым - так задаётся список ключей. При этом каждый из ключей из списка
подвергается "декорированию" (но не запятая).


### Версия списков значений с двумя ключами

Для каждого тэга списка значений существует его версия с двумя ключами. имена таких тэгов заканчиваются на '2':
`val-list` -> `val-list2`.

Первый ключ, как и в простой версии, следует после маркера элемента списка. Вторым ключем является следующая строка,
а описание начинается с третьей строки.

Пример:

```
<val-list2 type=table no-sec-title>
- CFGMETA_MK_ID_STRUCT
0
Преобразование имени структуры в числовой идентификатор структуры.
- CFGMETA_MK_ID_MEMBER
1
Преобразование имени поля структуры в числовой идентификатор поля структуры.
- CFGMETA_MK_ID_PAIR
2
Преобразование пары из имени структуры и имени поля структуры в пару числовых идентификаторов.
</val-list2>
```

Отображение:

|Имя|Значение|Описание|
|:---|:---|:---|
|**CFGMETA_MK_ID_STRUCT**|0|Преобразование имени структуры в числовой идентификатор структуры.|
|**CFGMETA_MK_ID_MEMBER**|1|Преобразование имени поля структуры в числовой идентификатор поля структуры.|
|**CFGMETA_MK_ID_PAIR**|2|Преобразование пары из имени структуры и имени поля структуры в пару числовых идентификаторов.|


Если задать текстовый вид атрибутом "type=text", то список значений будет выглядеть так:

**CFGMETA_MK_ID_STRUCT** - 0 -
Преобразование имени структуры в числовой идентификатор структуры.

**CFGMETA_MK_ID_MEMBER** - 1 -
Преобразование имени поля структуры в числовой идентификатор поля структуры.

**CFGMETA_MK_ID_PAIR** - 2 -
Преобразование пары из имени структуры и имени поля структуры в пару числовых идентификаторов.


### Тэги списков значений

Для вставки списков значений используются следующие тэги:


|Тэг|Описание|
|:---|:---|
|**arg-list**|Список аргументов, предназначен для описания аргументов (параметров) функций.|
|**attr-list**|Список атрибутов. Предназначен для описания атрибутов (обычно это относится к HTML/XML и подобным языкам)|
|**cli-opt-list**|Список опций комадной строки (CLI - Command Line Interface).|
|**val-list**|Список значений, без какой-либо более специализированной семантики.|
|**field-list**|Список полей. Обычно используется при описании полей (членов) структур и классов.|
|**opt-list**|Список опций, без какой-либо более специализированной семантики.|
|**ret-list**|Список возвращаемых значений (при описании функций/методов).|
|**def-list**|Список определений, без какой-либо более специализированной семантики.|
|**tag-list**|Список тэгов. Обычно используется для HTML/XML и подобных языков. Но, можно использовать и для описания тэгов в VCS, например, в Git.|
|**term-list**|Список определений (терминов), глоссарий|


### Атрибуты тэгов списков значений

Атрибуты тэгов списков значений позволяют настроить отображение списка значений в конкретном месте,
переопределяя глобальные настройки.

###### **Атрибуты**


|Атрибут|Описание|
|:---|:---|
|**type**|Тип отображения списка значения. Список значений может отображаться как таблица (table), или как текст (text). В последнем случае список определений будет отображаться как параграфы текста, в начале которых будет следовать ключ/термин, за ним, через дефис - описание.|
|**title**|Строка заголовка списка значений. Используется только при табличном отображении. Строка заголовка содержит разделяемый запятой список заголовком колонок. Выравнивание задаётся доеточием. Без двоеточия или двоеточие слева и справа - выравнивание по центру, двоеточие слева - выравнивание по левому краю, двоеточие справа - выравнивание по правому краю.|
|**value-style**|Стиль оформления ключа/термина, может принимать значения: <ul><li>`normal`, </li><li>`bold`, </li><li>`italic`, </li><li>`bold-italic`, </li><li>`backtick`, </li><li>`backtick-quote`</li><ul>|
|**section-title**, **sec-title**|Если задан этот атрибут, то в документе перед данным списком определений создаётся заголовок самого нижнего уровня (6го). Данный заголовок - заголовок внутри текущего раздела, при делении всего документа на отдельные статьи/страницы (при генерации многостраничного HTML, например) - такой заголовок не создаёт новой страницы, а располагается внутри текущей. Также этот заголовок не попадает в оглавление.|
|**no-section-title**, **no-sec-title**|Запрещает добавление заголовка. Должен идти самым последним атрибутом (есть баги), не требует значения, или можно задать любое значение. Аналогично указанию `section-title=""`.|
